## Wybór i przygotowanie zasobów

Przeanalizowano 476 plików w podfolderach, łącznie z GIF (liczba klatek w tabeli). Zakres alfa podaje wartości rzeczywistej przezroczystości pierwszej klatki; samo czarne tło nie jest traktowane jako alfa. Arkusz podglądowy: `docs/contact_sheet.png`.

- `Background/Tło(1).png`: pełna scena 1920×1080, nie tilemapa. Skalowanie nearest-neighbor do 960×540, bez cięcia i bez modyfikacji oryginału.
- `Dude/Dude_white.png`: RGBA 768×1280, siatka 3×5 komórek 256×256, 14 niepustych komórek. Ostatnia komórka (2,4) jest pusta. Nie traktujemy całego arkusza jako równomiernie wypełnionego zestawu animacji. Wybrano cztery boczne pozy: (1,3), (2,3), (0,4), (1,4), indeksy od zera. W każdej komórce wspólny kadr [48,68,192,248], pomniejszony do 72×90. Wspólna kotwica stóp zapobiega skakaniu klatek. Ruch w lewo: flip poziomy.
- `Dude/Dude2.png`: RGBA 256×256, obszar alfa [64,72,176,244]. Buddy korzysta z tego samego kadru [48,68,192,248] i skali 72×90.
- `Dude/Dude1.png`: alfa 255 w całym obrazie, czarne tło jest nieprzezroczyste — pominięto.
- `Dude_black.png` / `Dude_borderless.png`: inne układy 1024×1024; nie zastosowano automatycznego cięcia według siatki białego wariantu.
- `Trailer/Screen_base.png`, `Screen_progress.png`: pełne ekrany 1920×1080, referencja granatowo-turkusowego UI. HUD narysowany prostymi panelami Pygame, aby polskie teksty i cele były czytelne.
- Budynki, wnętrza, szachownice, sklep, przedmioty i GIF-y pozostają poza zakresem ulicznego POC. Pełna lista parametrów powyżej.

Pochodne: `assets/processed/`; odtwarzanie: `uv run python tools/prepare_assets.py` z katalogu projektu. Pillow jest potrzebne tylko podczas przygotowania, nie w grze. Font to domyślny FreeSansBold dostarczany z pygame-ce. Grafiki są zasobami użytkownika; projekt nie nadaje im licencji open source.
