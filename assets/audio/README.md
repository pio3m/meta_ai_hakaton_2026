# Chess Corp — original synthesized audio

All WAV files in this directory were synthesized locally for Chess Corp by tools/generate_audio.py, using only oscillators and seeded procedural noise. No recordings, third-party samples, music excerpts, network downloads, paid services or audio APIs were used.

Format: 22050 Hz, signed 16-bit PCM, mono WAV. Four 8-second loops and ten short effects. manifest.json records duration, peaks, format and reproducible SHA-256 hashes. Runtime uses the files, never the synthesizer.
